# Inua 360 - Kenya's First Autonomous AI Co-Pilot for SMEs

A comprehensive, production-ready web application designed for Kenyan SMEs with powerful analytics, AI agents, and full bilingual support.

## 🎨 Design System

### Primary Brand Color
- **Inua Orange**: `#FA6F20` - Vibrant, energetic color representing innovation and growth
- Complete with semantic colors: Success Green, Matatu Yellow, Warning Orange

### Key Features
- ✅ **Fully Responsive**: Mobile (393×852px), Tablet (1024×1366px), Desktop (1920×1080px)
- ✅ **Bilingual**: English/Swahili toggle on every screen
- ✅ **Dark Mode**: Complete theme with WCAG AA compliance
- ✅ **Offline PWA**: Works in rural areas (Kisumu, Mombasa, Eldoret)
- ✅ **Kenyan-Specific**: County flags, sectors, M-Pesa integration, KES currency

## 📊 Powerful Analytics Dashboard

### Main Features
1. **Key Metrics Cards**
   - Total Revenue (KES 750,000 +15.3%)
   - Active Reports (24 +8)
   - Team Members (23 +3)
   - Growth Score (88% +5%)

2. **Interactive Charts**
   - Revenue & Profit Trends (Line chart)
   - Team Growth (Area chart)
   - Sector Distribution (Pie chart)
   - Report Scores (Bar chart)

3. **Report History**
   - SME Report (85% score)
   - Funding Report (78% score)
   - Compliance Report (92% score)
   - Growth Score (88% score)

4. **Time Filters**
   - 7 Days / 30 Days / 90 Days views
   - Real-time data updates

5. **Action Cards**
   - Generate New Report
   - View Analytics Deep Dive
   - Export Reports as PDF
